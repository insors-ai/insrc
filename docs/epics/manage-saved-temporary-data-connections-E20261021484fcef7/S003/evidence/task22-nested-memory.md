The production planner bypasses attempt/feedback/final writes under Session policy. Unsupported Session provider modes refuse before data-bearing input, prompt construction or injected-provider access. Verified Session LLM admission remains t24/t25.

The first gate found that the fixture replaced too much of planning and tested only the provenance helper for replay. The correction removes that recursive-planner replacement. The authenticated child handoff bypasses task output writes under Session policy. The task writer receives explicit Saved policy for compatibility and cannot persist a known Session record through a Saved call. Remaining task/history/trace/Lance closure is t23.
