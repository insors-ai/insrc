# S003 task 4 — bounded session RPC admission

The six control/delegation methods are registered with exact primitive payload shapes, a 64 KiB serialized bound, fixed errors and no caller-supplied authority. Pending, failed and unknown session attachment attempts mark their socket before asynchronous work; these sockets cannot fall back to ordinary saved execution. Only static metadata is admitted on attached transports at this stage. Concrete temporary CRUD and analysis admission remain the later planned tasks.

The server supplies a private connection abort signal independently of individual request completion. Claims are checked against the owner handle, root, epoch, generation and live attachment before dispatch and delivery. Disconnect invalidates completed-call descriptors as well as in-flight admission. The main router handles every connection-management and legacy connection method locally. Local authority cannot be projected onto a worker channel. Persistent workflow/build/review/tracker and unclassified methods refuse before handler or worker access; streaming refusal is a terminal fixed error frame.
