Narrative

Implemented VS Code + JetBrains consumers. Live acceptance pending user manual testing.

Shared layout/state schematic for VSCode extension and native JetBrains Connections manager. Both use the same scoped rows, safe draft and truthful recovery; JetBrains application Settings explicitly selects an open project before a project-owned manager. This is design preview only. Implemented in dedicated TypeScript webview and native Swing manager. Save, Test, Remove and recovery actions have independent advertised-capability admission. Live UI validation is assigned to the user after plugin installation; this schematic is not execution evidence.
