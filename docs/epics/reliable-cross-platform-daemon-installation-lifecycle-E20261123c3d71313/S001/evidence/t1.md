# t1: installer contracts and location resolution

Implements the foundation wire types and strict Ajv schemas in `src/installer/`.
The modules import only Node builtins and the existing Ajv dependency. Existing
application PATHS and IPC payloads are unchanged; no daemon, DB, provider or IDE
runtime is loaded.

The pure resolver supplies per-user/per-installation Windows pipe names from
a caller-supplied verified SID, and preserves the Unix daemon.sock default.
It rejects traversal, UNC/network homes, Windows aliases and overlong Unix
socket paths. Read-only filesystem admission rejects symlinked control roots,
unknown/network filesystem families and absent platform filesystem probes.
Windows volume qualification is supplied by the t2 native binding; unavailable
qualification is not converted into a successful local-filesystem assertion.

Bridge helpers validate startup state and per-request outcome evidence; they
do not start a helper process, open a named pipe or implement the JetBrains
adapter. Nonce/version matching and the three-second deadline prevent dispatch
before ready. Absent write evidence stays unknown; positive not-written proof
cannot later become a write, and possible dispatch cannot become cancelled.
