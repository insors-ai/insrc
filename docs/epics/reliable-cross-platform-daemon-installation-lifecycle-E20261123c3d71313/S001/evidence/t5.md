# s1/t5 — verified bundle candidate preparation

Added strict release descriptor/inventory admission, bounded HTTPS download/discovery, lazy streaming yauzl extraction, immutable candidate publication and full retry revalidation. This prepares payloads only: it never selects a release, runs npm/build, starts/stops a daemon, invokes hooks or opens application databases.

Descriptors must be qualified, exact-target/protocol/pinned-runtime records. Predecessor compatibility derives from the locked controller rather than an optional caller assertion. Download and manifest digests must agree, redirects remain HTTPS with bounded hops, and actual bytes/size are verified while writing an exclusively created owned file. Validated descriptor data is cloned/frozen before asynchronous work.

ZIP extraction uses lazyEntries, strictFileNames and validateEntrySizes plus bounded compressed/expanded/individual bytes, entries, filesystem nodes, path depth and ratio. It rejects traversal, absolute/drive/UNC/ADS/backslash/control/reserved names, ambiguous encoding, Unicode/case/component aliases, duplicates, symlinks/special files/attributes, encryption and unsupported methods. Files are exclusively created and flushed; inventory membership/digests/sizes/modes and daemon/manager/TUI/hooks/runtime/control identities are checked before publication. Expanded runtime files must match the already verified bootstrap distribution, not merely a caller-labelled Node version. No extracted code executes.

The retained-lock adapter now supplies exclusive same-volume directory publication: renamex_np(RENAME_EXCL) on macOS, renameat2(RENAME_NOREPLACE) on Linux, MoveFileExW without REPLACE_EXISTING and with WRITE_THROUGH on Windows. An existing release is never replaced. Existing immutable candidates require the exact descriptor receipt plus complete file/runtime revalidation; a marker alone cannot establish success. Cancellation/failure removes only the unique owned stage. Controller location is frozen so an admitted lock cannot be retargeted accidentally.
