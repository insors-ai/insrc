# s1/t7 — operation-owner immediate forwarding

The ordinary manager routes stop/immediate to the existing operation before mutation admission. The owner retains the native lock and exclusively sends the second s4 shutdown request. Its request uses the original instance, operation, completion endpoint and completion nonce. Duplicate callers join one owner-side promise. No process identity probe, signal, automatic escalation, replacement runner or competing controller writer was added.

The control lane exists only during quiescing. Discovery is manager-owned operation metadata, published under the native lease using the existing atomic writer and read using the existing private bounded-record reader. A fresh 256-bit owner-session nonce is a capability protected by POSIX user-only records or the inherited native Windows user DACL. Both endpoints bind the full installation/operation/owner-session identity; endpoint addresses are derived locally rather than accepted from wire input. The controller phase, durable owner record and live manager snapshot are checked. Missing/stale/dead owners return escalation-unavailable and require explicit reconciliation; a free native lock alone does not authorize action.

## Ownership and relationships

| Boundary | Writer / owner | Readers and lifetime |
| --- | --- | --- |
| controller.json | One native-lock-owning manager | Forwarders inspect phase only; never acquire or alter ownership |
| operations/<operation>/control.json | Same operation owner | Same-user forwarders read a bounded private capability; stale records confer no new mutation authority |
| Local control socket / pipe | Current owner session | At most 32 clients, one bounded request/reply per connection, absolute three-second I/O lifetime |
| s4 shutdown/completion evidence | Existing lifecycle port and owner | Forwarders supply only immediate intent; original completion identity is retained |

The owner remains asynchronous during drain and closes the control listener before releasing its operation lock. A partial frame cannot indefinitely delay closure. Compatibility: the existing ManagerRequest/Event contracts are unchanged; install remains terminal-only. Production peers and target qualification are unchanged. Windows pipe execution and cross-user ACL behavior require authentic Windows qualification; no fixture is represented as that qualification.
