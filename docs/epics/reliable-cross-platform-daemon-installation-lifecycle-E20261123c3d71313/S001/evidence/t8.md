Implementation, rewrite-scoped checks and registered task validation are complete. All eight S1 tasks have passed; the Story BUILD awaits human approval.

The all-TTY terminal owns delivery/source selection, final install/upgrade confirmation and exact Ollama consent. Coding CLIs are recommendations only. Upgrades retain recorded delivery and bind both upgrade acceptance and dependency consent to current offers. The ordinary manager wire protocol cannot invoke install or carry terminal consent. Missing s2/s3/s4/s5 ports return capability-unavailable instead of invented production behavior.

The selected immutable release's private Node runs the TUI in the same foreground terminal only after exact-ready commit and native lock release. Selection revalidates candidate inventory, controller revision/selection and live daemon identity/endpoint. Installer-owned launchers are atomically updated to the successor digest-bound bootstrap under the existing operation lock, with a fresh exact-ready snapshot check; exact template validation preserves foreign or user-modified files; source scripts/insrc is unchanged. TUI failure retains the completed install and prints the absolute, quoted private-runtime retry command. TUI exit leaves the fixture daemon alive. Explicit INSRC_HOME scopes shared config, socket and daemon-owned data to the selected home; default home behavior is preserved.

Terminal cancellation is checked before mutation/disruption, after preparation, after settled migration ownership and before activation. Owned async work settles before releasing the lease. Cancellation during completed activation preserves the truthful ready result and suppresses TUI launch. Cancellation after disruption leaves a blocked operation for explicit recovery. No daemon signals, automatic escalation, rollback or automatic relaunch were added. Programmatic readline close is distinguished from user close. Peer error messages are bounded and sanitized before durable schema validation.

## Relationships and ownership

| Boundary | Owner | Behavior |
| --- | --- | --- |
| Canonical shell / PowerShell script | User's foreground terminal | Provisions private bootstrap runtime; preserves I/O, operation identity and installer exit status |
| Terminal bootstrap | Same terminal | Owns interactive consent; carries no IDE-filled consent flags |
| Controller / operation | Manager with native lease | One writer; repeats exact dependency consent validation under lock |
| Ready selection | Delivery + lifecycle ports | Verified immutable release and exact installation/readiness evidence |
| Installed launcher | Installation-private bin directory, serialized by the same operation lock | Atomically replaces its exact owned template with the successor bootstrap; stale/busy publishers fail and foreign/user-modified files survive |
| TUI child | Foreground terminal | Uses selected release Node/entry and installation home; no DB access by installer |

No public ManagerRequest/Event shape changed. Cancellation and upgrade consent use only the terminal capability API. The target is supplied as a compile-time constant by release publishing, not an environment/wire bypass. Windows native execution and owning-peer implementations remain later qualification work.
