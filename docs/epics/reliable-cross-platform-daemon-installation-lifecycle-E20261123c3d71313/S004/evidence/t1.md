# S4/T1 — lifecycle evidence and daemon data lease

Task: `TASK-c3d71313f34bce71-s4-t1`, insors-ai/insrc#296.
Source: approved S004 LLD revision 6 and PLAN revision 1.

Implemented private strict decoders for existing daemon identity, shutdown
request/ack/completion, live launch admission, migration exit receipt and ready
evidence. Bind the exact installation, release, instance, operation, session,
nonce, inventory digest, purpose and canonical endpoint/receipt paths. Exact
duplicates are accepted; an immediate request cannot be downgraded to graceful.
Ready evidence requires activation admission. Validating an exit receipt never
constitutes successful hook execution.

The daemon data lease uses the existing native OS lock at
`<home>/install/daemon-data.lock`, separate from the manager's operation lock.
It requires existing private real roots and allocates no enrollment or stores.
Retained strong references prevent native external-handle GC from releasing a
live lease. Application resource disposal waits for the actual store/worker
closure barrier and coalesces callers. Both success and failure retain the OS
lease until actual process exit. The legacy primitive's `close(void)` does not
attest native release, so this lease deliberately never calls it. Actual
wrapper exit proof and ownership reconciliation remain required by later
tasks. Existing native control semantics and shared wire types are unchanged.

## Boundaries

The boot entry, live owner rendezvous, lifetime wrapper, receipt filesystem
publication, control routing and production manager peers belong to subsequent
S4 tasks. The first task adds their private validated evidence/lease building
blocks; it does not enable a production install/start/update path. S1/S2 runtime
store corrections and S1 manager action-specific capability admission remain
owner prerequisites. S5 owns hook/journal decisions.

No installed host daemon or Ollama state was changed. Isolated macOS fixture
results do not qualify Linux, Windows, immediate native exit, real DB recovery
or the complete lifecycle; those checks remain later evidence work.
