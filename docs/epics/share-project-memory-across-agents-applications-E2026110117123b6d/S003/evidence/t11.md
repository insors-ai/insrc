# S3 task 11 — trusted admission and error boundaries

Added private pure AdmissionTransforms and store/admission-policy. Raw input must
be the exact versioned input/source envelope; protected metadata is rejected
before host invocation. Host output is snapshotted, envelope-checked, attested,
and finalized with exact UTF-8 source/request hashes. Unverified times are nulled
in both places. The final bounded snapshot and queue persist remain outside the
unchanged host error catch. No public option/export or S2 frame change.

The actual EmbeddedMemoryService public submit method is composed with the real
queue, owned native store and transforms in the test harness. MemoryFactory
production wiring remains t13, as the plan requires. The harness owns cleanup
explicitly; it does not pretend the t12 lifecycle adapter is already implemented.
No models are called. Trusted host fixtures explicitly attest origins and authorize
registered source lifecycles, including an authorized new lifecycle after forget.

Tests compare all queue file hashes before/after protected-input, policy error,
missing/malformed attestation, envelope mutation, output-size/final-metadata-size
overflow and retained/recycled terminal identity conflicts. Exact retries retain
the original accepted/terminal result, root generation and queue bytes. Source
redaction, Unicode/CRLF hash identity, verified future time and unverified null time
are checked against real persisted frames and committed provenance. Existing guard
tests cover exact UTF-8 spans, authority and evidence derivation.

Verification: 16 focused admission/direct-S2/guard tests pass, zero skips; four
admission cases pass again after adding the final-metadata-only overflow case
(t11-final-overhead.tap). Package and root typechecks pass. No full sweep here.

The host remains the trust boundary for authenticated origin and lifecycle truth;
this module cannot certify a dishonest injected HostPolicy. No semantic worker,
default user authority, host adapter, provider call or configuration change.
