# S3 task 12 — store owned work and rollback

StoreOwnedWork implements the existing private runtime participant contract.
Mutation/read admission stops synchronously; queue proof reads remain callable
through queue drain and close. The store closes proof admission only when its
own close begins. Queue-before-store composition is exercised with the actual
EmbeddedMemoryService, real queue/store and a held native write followed by a
queue-owned proof lookup. A short drain deadline leaves ownership held until the
actual native promise and proof settle; no queue callback runs inside the writer.

Writer accounting distinguishes read-lease-owned capture/head operations from
independent proof/write work. A failed capture's unclosed native reader is retained
and counted even when no lease can be returned. Active reads cancel at their next
guard boundary but retain their native resources until actual work settles. Idle
leases close on drain. Close waits stay pending, are idempotent, and attempt every
reader/table/connection after actual settlement; any unverifiable cleanup retains
the owner and strong native-resource references.

rollbackStartup stops all allocated participants, attempts each drain/close in
dependency order despite earlier failures, and releases the owner only on fully
verified cleanup. Typed original initialization errors survive successful rollback.
The helper is private; production host wiring remains task 13. Existing runtime
participant ordering is preserved, with no public options or protocol changes.
