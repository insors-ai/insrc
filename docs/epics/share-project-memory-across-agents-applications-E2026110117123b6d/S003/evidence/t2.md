# S3 / t2 — persisted codecs and embedding profile

Added package-private typed row/payload schemas, bounded canonical row codecs,
qualified physical identities, explicit nullable Arrow schema, batch row/byte
checks and the versioned text/Float32 embedding recipe. Reused S2 snapshot,
shape, digest, decimal and scope helpers after an analyzer/source reuse pass.
No backend imports, public wire changes, model calls or native store writes.
Referential, transition, provenance and publication guards remain later tasks.

Validation on Node 22.23.2/macOS:

- Package TypeScript/declaration build passed.
- [Codec/profile tests](t2-tests.tap): 9 passed, 0 failed/skipped, including
  required/unknown payload fields, envelope disagreement, canonical negative
  zero/Unicode, source/lineage/outcome shapes, safe batching, profile mismatch,
  vector bounds and caller mutation during async schema construction.
- The first daemon gate correctly identified that helper-level profile tests
  did not prove plan metadata rejection. Added snapshotPlanRows and a real
  vector-bearing row-plan test covering missing/model/dimension/normalization
  mismatch, scalar-only behavior and unchanged input bytes. This prepares only
  the row/profile portion; causal/provenance guards remain t5.
- Packaging now permits only the existing root/queue paths plus dist/store and
  requires the three modules introduced here, so new files do not break the
  existing tarball assertion. Final module/native verification remains t14.
- [Packaging run](t2-packed-first-attempt.tap): four cases passed; isolated
  consumer hit its existing 10-second natural-exit timeout. The failed case
  [passed on focused retry](t2-consumer-retry.tap) with the same unchanged limit.
  No failure was hidden or converted to a pass; host load was 19.59/13.34/11.54
  when checked, which is context rather than proof of the timeout's cause.

This is structural codec evidence, not native publication/crash qualification.
