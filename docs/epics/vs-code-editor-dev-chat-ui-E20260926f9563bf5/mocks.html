S001 · Conversation fidelity

Read a faithful turn

  • Your prompt echoes live as its own message, not only after reload.
  • Assistant text per step is shown, not just a step label.
  • Tool rows show the real command (e.g. the full grep …).
  • Session name truncates to 32 chars with an ellipsis.
S002 · Layout & input

Usable at any length

  • Header fixed on top, input pinned at the bottom; only the transcript scrolls.
  • Send button, and a Stop button while a turn runs.
  • One animated progress widget above the input replaces repeated inline “thinking” rows.
S003 · Rich rendering

Legible, compact

  • User vs assistant visually differentiated (accent, alignment, border).
  • Collapsed by default — long user or assistant messages clamp to a 3-line preview; tool results & inline diffs collapse to their caption header. A single chevron icon (▸ / ▾) toggles every one.
  • Markdown & JSON render in type-appropriate widgets, not flat text.
S004 · Approvals & auto-mode

Never silently blocked

  • Permission requests surface in-chat with Approve / Deny.
  • The decision is relayed to the CLI session.
  • Auto-mode relays a permission-mode flag and shows in the status bar.
