LLD: Show each changed section of a turn as a diff widget

Epic: show-each-changed-section-turn-s   Story: S001   Rollout: standalone

Summary

When the assistant changes files during a chat turn, the dev chat shows each changed section of each file as its own widget: the path, the lines added and removed, line numbers and the theme's diff colours, cut to 8 lines until the reader opens it. The plugin gets the sections by asking git, after every tool call, how the working tree differs from the snapshot it took when the turn started.

A section that changes again updates its widget in place, and the widgets are saved with the chat so they are still there, in their latest form, after a reload. One limit: if the reader switches chat, closes the panel or reloads the window while a turn is running, the rest of that turn shows path lines as today, not widgets.

1. Contract details

1.1 createGitBaseline

createGitBaseline(deps: GitBaselineDeps): WorkspaceBaseline
// snapshot(cwd)  -> { ref: tree id, index: private index path }
// changes(handle) -> patch | '' | undefined

The snapshot is a git tree written through a private copy of the index, so the user's own index and status are never touched. A check writes a second tree and diffs the two.

LimitValueWhy
Lines shown folded8Chosen by the user
Lines kept per section400Keeps the saved chat small
New widgets per check20A generated tree must not flood the chat

2. Error paths

  • Not a git folder: no snapshot, no widgets; path lines as today.
  • The comparison cannot be read: one line says so, once per turn; later checks still run.
  • A file git ignores: no widget; the path line is written so the edit leaves a trace.
Open question: should a withdrawn section leave a trace in the chat?

3. Test strategy

Unit tests for the parser and the reconciliation; integration tests for the host over a fake governor; real git in temporary repositories; two live tests against the installed CLIs.
