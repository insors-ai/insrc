Narrative

Standalone feature · shared companion template — how the four companion types plug into one page shell.

The workflow finalizer builds one header context per document and hands each authored definition to its plug-in. A plug-in returns only two things: the visual and its description tables.

The shared shell owns the page layout and the single pan/zoom runtime, so every companion looks and behaves the same.
