Narrative

Epic E1 · Delivery read model in the daemon — the data the Delivery board reads, one snapshot per refresh.

The daemon assembles one DeliverySnapshot per board refresh. Each DeliveryItem is an Epic, Story or task, linked to its parent so the board can draw the hierarchy, and carries the evidence (approved artifacts) that proves the stage it has reached.

Notices hang off both the snapshot and individual items, so a ledger problem can be flagged at the right level. TaskValidation records which planned tasks passed validation in the build.
