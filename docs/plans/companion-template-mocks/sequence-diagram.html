Narrative

Epic E2 · Delivery board in VS Code — how the board reads delivery state from the daemon.

A refresh flows from the webview through the board host and delivery client to the daemon and back. The host numbers each request and drops any response that is older than the latest, so a slow reply never overwrites a newer board.

Selecting a story loads its planned tasks; opening an evidence record hands off to the existing review pane.
