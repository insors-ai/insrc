Narrative

Story S002 of Epic “Build VS Code plugin UI integration” — show a document's functional requirements from its structured record.

When a reviewer opens a generated document, the pane replaces the generated bullet list under “Functional requirements” with one row per requirement, built from the record the artifact carries.

Each row shows the requirement's stable id beside its outcome, so the same commitment can be recognised across stages. The approve and request-changes controls are unchanged from S001.
