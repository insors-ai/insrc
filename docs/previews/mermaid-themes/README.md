# Insors branded Mermaid previews

Source: Insors Brand Guideline, June 2025, pages 5 (palette) and 6 (Poppins).

Exact brand colors: #102D1A, #4B9988, #6AB489, #92CD87, #C2E484, #D1E736. Light/dark surface tints are derived adaptations, not additional official brand colors. Pear is an accent; dark green carries text on lighter greens. No logo was recreated.

The JSON file contains reusable Mermaid configurations for both themes. HTML copies embed local Poppins fonts and the bundled runtime for offline use. These previews do not change the production renderer or approved source definitions. The viewer still uses fit-to-view; large graphs may require zooming.

Apply insors-diagram-overrides.css with the JSON configurations for Mermaid 10 ER label contrast. Poppins 400/600/700 is embedded in the preview HTML; production integration also needs these font assets.
