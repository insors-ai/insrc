## Change and provenance

- `src/installer/runtime-policy.json` retains the six official Node22.22.1
  archive digests and adds independent executable/inventory hashes, byte counts
  and deterministic minimal distribution profiles. Windows profiles include
  separately pinned official headers and architecture-specific `node.lib`.
- Assets were fetched from the official Node22.22.1 release and checked against
  its `SHASUMS256.txt`; existing six archive pins matched that source. Input
  fixtures are outside application/IDE payloads and outside installed runtimes.
- `scripts/generate-runtime-profiles.mjs` reuses publisher inventory/hash
  helpers and existing installed archive readers. It reads verified bytes in
  memory without extracting files, spawning processes or executing target code.
  Inventory ordering is explicitly independent of locale/archive entry order.
- `src/installer/runtime-metadata.ts` defines runtime-only receipt, inventory,
  result/layout types and fixed bounds. The layout helper binds full runtime
  identity and explicit home. Public contracts are unchanged.
