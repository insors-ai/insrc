Component map — Docgen render spine

docType: component · scope: the modules that turn a definition into companion HTML

Context

Purpose

This component-dependency map shows how a companion definition flows into finished HTML: the finalizer calls a renderer, which maps the definition to an IR and hands it to the shared shell (with an oversized fallback). It exists so a reader can see the module boundaries and what depends on what — without tracing imports by hand.
