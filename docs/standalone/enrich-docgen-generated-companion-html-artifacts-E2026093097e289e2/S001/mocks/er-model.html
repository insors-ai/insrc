ER model — Epic / Story

docType: er · scope: ER model of the workflow artifact ledger

Context

Purpose

This entity-relationship diagram shows the data model an Epic groups: one Epic owns many Stories, each Story owns many acceptance Criteria. It exists so a reader can understand the persisted shape — the classes, their key fields, and how they relate — without opening the source design document.
