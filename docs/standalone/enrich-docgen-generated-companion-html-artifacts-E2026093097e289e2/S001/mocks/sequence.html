Context

Purpose

This sequence diagram traces the calls made when the controller synthesizes an LLD: the MCP tool hands the body to the orchestrator, which validates companions, renders them, and writes the artifact. It exists so a reader can follow the control flow and where a retry happens — without stepping through the code.
