Prepare TaskGarden

Repository brief

Use the prepared taskgarden-demo repository and demo-baseline tag. Keep the application independent of insrc: no server, database account, or application login.

  • Add, complete, reactivate, and delete tasks.
  • Filter by All, Active, and Completed.
  • Persist tasks across reloads with local storage.
  • Keep task types, storage, filter helpers, and UI components easy to locate.
  • Provide documented development and test commands and a small passing baseline suite.

Seed data and change scope

Seed “Write release notes”, “Review onboarding copy”, “Fix mobile navigation”, and “Publish the demo”.

On screen · test one embedding

curl --fail --silent --show-error http://localhost:11434/api/embed \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen3-embedding:0.6b","input":"TaskGarden stores tasks locally."}' \
  | node -e 'let s="";process.stdin.on("data",c=>s+=c);process.stdin.on("end",()=>{const r=JSON.parse(s);const v=r.embeddings?.[0];if(!Array.isArray(v)||v.length!==1024)throw new Error("Expected a 1024-dimensional embedding");console.log("Embedding OK:",v.length,"dimensions")})'

Success checkpoint: the command reports Embedding OK: 1024 dimensions. A successful download alone does not demonstrate inference.
