Shared-workspace boundaries

Claude writes only its tracked design artifacts. Codex owns the catalog-search implementation and tests. Both may create framework-owned records; let insrc manage those. No parallel edits to application code, migrations or shared files. At the build boundary, refresh the code/index context if the working revision changed; do not run Git resets or bulk-stage the other chat’s documents.

Traceability focus

Use synthetic library data. Show recorded requirements, review findings, approvals, tests and completion. Explain relevance to healthcare/finance change-control reviews without claiming regulatory certification, immutable audit storage, signed identities or guaranteed local inference.
